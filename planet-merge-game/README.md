# 행성 합치기 게임 (Planet Merge Game)

초등학교 4학년 2학기 과학 태양계 수업용으로 만든 웹 게임입니다.
같은 것 두 개를 부딪히면 다음 단계로 합쳐지는 방식이며, **게임 두 가지**가 들어 있습니다.

**바로 하기**: https://goranipark.github.io/planet-merge-game/

## 두 가지 게임

| | 🪐 크기 순서 게임 (`?mode=size`) | 🛰️ 거리 순서 게임 (`?mode=distance`) |
|---|---|---|
| 배우는 것 | 천체의 **실제 지름** 순서 | 태양에서의 **거리** 순서 |
| 사다리 | 소행성 → 달 → … → 목성 → 태양 (11단계) | 수성 → 금성 → … → 해왕성 (8단계) |
| 공의 크기 | 천체의 실제 지름 | **공전 궤도**의 크기 |
| 더 있는 것 | — | 순서 3지선다 퀴즈, 엔딩 실제 거리자 |

두 게임을 나란히 두는 것이 이 자료의 핵심입니다. 한쪽만으로는 생기기 쉬운
**"큰 행성이 바깥에 있다"는 오개념**을, 두 게임을 비교하면 학생이 스스로 깨뜨릴 수 있습니다.
자세한 설계 의도는 [concept2.md](../concept2.md)에 있습니다.

## 학습 요소

- 새로운 천체(궤도)를 처음 만들면 정보 카드가 뜨며 실제 지름 또는 태양까지 거리를 안내
- 거리 순서 게임은 카드 앞에 **순서 퀴즈**를 내서, 순서를 모른 채 지나가지 않게 함
- 거리 순서 게임의 **🔭 실제 거리 보기** — 태양~해왕성을 실제 비율로 그려
  교과서 그림과 달리 안쪽 네 행성이 한곳에 몰려 있음을 보여 줌 (수업 정리용)
- 설치 없이 링크만으로 크롬북·아이패드·윈도우에서 모두 실행
- **학급 코드 필수**: 시작할 때 학급 코드를 넣어야 순위표를 씁니다. 전국 순위표는 닫혀 있습니다.
  교사가 "새 학급 만들기"로 6자리 코드를 발급받아 칠판에 적거나 `?room=코드` 링크로 배부합니다.
  코드 없이 들어오면 순위표 없는 **혼자 연습**이 됩니다 (개인정보는 여전히 수집하지 않음)
- **순위표는 게임별로 따로 집계** (점수 체계가 달라 섞을 수 없음)
- **공용 기기 배려**: 최고 점수·별명·본 정보 카드는 탭을 닫으면 초기화 (`config.js`의 `RESET_ON_TAB_CLOSE`)

## 이 저장소를 복사해서 쓰시는 분께 ⚠️

이 저장소를 그대로 복사(fork)해 배포하면 **원본과 같은 순위표를 함께 쓰게 됩니다.**
학교별로 따로 운영하시려면 둘 중 하나를 선택하세요.

1. **순위표를 끄기** — `src/game/leaderboardConfig.js`의 `FIREBASE_CONFIG` 값을 모두 빈 문자열(`''`)로
   두면 "이 기기에만 저장되는 연습용" 순위표로 동작합니다.
2. **내 순위표 만들기** — [FIREBASE-설정안내.md](../FIREBASE-설정안내.md)를 따라 본인 Firebase 프로젝트를
   만들고 그 설정값으로 교체하세요.

## 개발자용 안내

```bash
npm install         # 최초 1회
npm run dev         # 개발 서버 실행 (http://localhost:5173)
npm run build       # 배포용 빌드
npm run check:orbits # 거리 순서 게임의 행성 데이터·그림 크기 검사
```

게임 난이도와 조작감은 [`src/game/config.js`](src/game/config.js) 한 파일에서 조정합니다
(병 크기, 천체 크기 배율, 게임오버 판정, 낙하 쿨다운, 중력·마찰, 모드별 점수표,
순서 퀴즈 on/off, 점검 모드).

### 모드 구조

한 게임에 필요한 것(천체 목록·점수·그림·안내 문구)을 `src/game/modes/` 안에 한 덩어리로 묶어 두었습니다.
엔진과 화면은 "지금 어떤 모드인지"만 알면 되므로, 새 모드를 추가하려면 파일 하나를 만들고
`modes/index.js`의 `MODES`에 한 줄 더하면 됩니다.

| 파일 | 내용 |
|---|---|
| `modes/sizeMode.jsx` | 크기 순서 게임 (데이터는 `objects.js`) |
| `modes/distanceMode.jsx` | 거리 순서 게임 (데이터는 `orbits.js`, 그림은 `orbitSprites.js`) |
| `modes/index.js` | 모드 목록·조회·잠금 판정 |

아직 준비되지 않은 모드는 모드 파일에 `comingSoon: true`를 적어 두면 "공사 중"으로 잠깁니다.

### 점검 모드

`config.js`의 `MAINTENANCE`를 `true`로 두고 배포하면 두 게임이 모두 잠기고
"잠시 준비 중이에요" 안내만 나옵니다. 게임 엔진도 만들지 않고 순위표도 부르지 않으므로,
순위표를 초기화하거나 새 버전을 올릴 때 기록이 섞이지 않습니다.

효과음을 음원 파일로 교체하려면 [`src/game/soundAssets.js`](src/game/soundAssets.js)의 안내를 따르세요.

`main` 브랜치에 push하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.
